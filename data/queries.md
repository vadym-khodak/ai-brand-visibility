# Перелік запитів / Query list

80 небрендованих запитів українською та англійською мовами. В основному зборі перед кожним запитом додавалося речення «Я живу в Україні.» / «I live in Ukraine.».

80 unbranded queries in Ukrainian and English. In the main collection each query was preceded by «Я живу в Україні.» / «I live in Ukraine.».

Наміри / intents: BEST — загальна рекомендація / general recommendation; TASK — конкретна задача / specific task; COMP — порівняння / comparison; PRICE — ціна / price; TRUST — довіра / trust.

Машинозчитувана версія / machine-readable version: `queries.csv`.
